# 电子书 / 素材来源

## 常用

| 来源 | 用途 | 注意 |
|---|---|---|
| 微信读书 / 得到电子书 | 找原文引文与页码 | 页码以纸质版为准，电子版页码不可直接引用 |
| 出版社官网 / 电商详情页 | 核验版次、ISBN、封面 | 封面取官方图，别用买家秀 |
| 豆瓣读书 | 评分、简介、读者评论 | 评分写「豆瓣 X.X（抓取日期）」 |
| 国家图书馆 / ISBN 查询 | 核验书名作者 | 译名以版权页为准 |

## 素材红线

- 书封只用**可核验的真实图**（扫描/实拍/官方图），禁模型生成、禁贴图修补。
- 引文长度控制在合理引用范围；大段内容改转述。
- 图片素材（y2 用的生活场景）可以出图，但**不许出「书封」**，也不许让模型画「假装是照片」的图形。
- 下载的图片留 `source_url` 与抓取日期，写进 `06-image-assets.md`。

## 找不到封面怎么办

1. 找同版次官方图（出版社/电商）；
2. 找高清实拍（自己拍：书平放、光从侧面、别拍反光）；
3. 都拿不到 → **换书或阻塞**。不许生成封面（D16）。
