# 03 内容审核（口播稿能不能直接念）

**这是硬闸门**，`run_all.py` 在配音前跑；红灯回 02 改稿。
它审的是「内容与口播」，不是事实真伪（改写自成熟文案时，事实由原稿负责）。

```bash
python3 ours/audit_script.py --script 02-final-script.md --sources sources/a.txt sources/b.txt \
    --book "被讨厌的勇气" --out 03-script-audit.md
# 输出：03-script-audit.md（人读）+ metadata/03-script-audit.json（闸门读）
```

## 六项判据

| # | 项 | 红灯（回 02） | 黄灯（可发，建议改） |
|---|---|---|---|
| 1 | **覆盖率**（原稿信息有没有丢） | 总覆盖 <55%；单篇 <40%（说明两篇只用了一篇） | 总覆盖 <70% |
| 2 | 句长 | 任一句 >32 字（念不完） | 28–32 字 |
| 3 | 口语化 | 书面词/黑话 ≥3 个（综上所述/赋能/抓手/闭环/链路/底层逻辑/颗粒度/维度/护城河…） | 1–2 个 |
| 4 | 对话感 | 「你/您」每百字 <2 次且全篇无问句（不是对着观众说） | — |
| 5 | 事实保留 | 原稿数字被删 ≥3 个 | 删 1–2 个（确认是有意） |
| 6 | 硬伤 | 书名号不配对、句末无标点、最后两句无 CTA | 绝对化广告语、连续重复字、没提书名 |

## 覆盖率怎么算（可复现，不是拍脑袋）

源稿逐句比对：新稿任一句与它有 **字符 bigram Jaccard ≥0.35**，或源稿里 **≥8 字的连续片段**原样出现在新稿 → 该句算覆盖。
覆盖率 = 被覆盖句数 / 源稿句数；多篇取平均，并单独列出每篇（防「只用了第一篇」）。

> 这是「信息有没有保住」的下限判据。换角度重述也算覆盖（bigram 相似度能抓住同义改写）；整段换题材/换观点会被判丢失。

## 改了什么，记在哪

`02-rewrite-record.md` 记「保留 / 合并 / 删掉（含原因）/ 补的 CTA」；
`03-script-audit.md` 记「该保的有没有保住、念出来顺不顺」。两份一起看就知道这版改了哪里、为什么。

## 红灯的常见修法

| 红灯 | 修法 |
|---|---|
| 覆盖率低 | 回 02 把没覆盖的句子补进去（换角度说也算），或拆成系列 |
| 句子太长 | 在「，」处断开；一句一个动作 |
| 书面词 | 直接换成大白话（「赋能家长」→「帮家长」） |
| 没有对话感 | 加一句「你是不是也这样？」；把「家长们」改成「你」 |
| 数字被删 | 确认是否要保留；要保留就写回去，不要含糊成「很多」 |
| 没 CTA | 结尾加「想读的点开橱窗」 |

## 什么时候可以跳过

只有一种：稿子是你自己写的、且已经人工读过（`run_all --skip-audit`）。
默认不跳过——这次就是因为「啥都不审」被判不合格。
